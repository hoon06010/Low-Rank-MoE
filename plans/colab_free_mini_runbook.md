# Colab mini experiment — public guide

The historical mini experiment used four LR conditions, seed 17, 768 optimizer steps and 3,145,728 targets per condition.
Use configs/colab_free_mini_final/ for the completed recipe; configs/colab_free_mini/ contains earlier settings.
The experiment report is reports/colab_free_mini/experiment_summary.md.
Read plans/m9/runbook.md and plans/m9/data_terms.md before preparing data.
Scripts under scripts/ implement packaging, execution and recovery. They require separately prepared data and explicit runtime settings.
Personal account identifiers, service quotas and operator approvals are omitted. This is a protocol guide, not a ready-to-run private deployment.
